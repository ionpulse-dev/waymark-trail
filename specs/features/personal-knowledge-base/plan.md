# Plan: Personal knowledge base skill

## Overview

The skill text is written as Markdown parts. The shared rules go into
`src/common.md`. What only one person needs goes into `src/personal.md`. The
build from `skill-build` joins them into `personal-knowledge-base/SKILL.md`.

## Components Affected

- `src/common.md` — shared rules (autonomy levels, reading, writing, document format, moving, secrets, limits).
- `src/personal.md` — role text and the start message of the personal skill.
- `src/frontmatter/personal.yaml` — description and version.
- `personal-knowledge-base/SKILL.md` — generated by `build.sh`.

## New Files

- `tests/skills.test.sh` — content checks for both finished skills (the team spec adds its own checks to it).

## Technical Approach

- The role part comes first, so the start message is the first thing the agent reads. The shared rules follow.
- The text is written in plain words (Simple English). It holds no commands for the person. The agent uses ordinary Git commands.
- The autonomy table is a Markdown table in the role part. The shared rules say when to show it again.
- Reading rules follow the steps path, file name, title, description, body, with a budget of 5 documents and about 800 tokens.
- Writing is a fixed list of steps: pull with rebase, compare the last commit of the document, check the work, commit under the person's name, push. Never force a push.
- The document format section follows MKBase 1.0 (`standard/mkbase-1.0.md`), written as rules for the agent. Its field table is identical to the standard's.
- Defaults: the commit message starts with `kb:`.
- Size: the finished personal skill stays below 12 KB, because it loads into every session.

## Cross-feature Dependencies

- `skill-build` (implemented): provides the build and the check.
- `document-standard` (implemented): defines the document format.
- `team-knowledge-base` reuses `src/common.md`. A change to it changes both skills.

## Risks

- The agent may ignore a rule. The README says that nothing enforces the skill.
- A long skill costs context in every session. The size test guards the limit.
- The agent may not load the skill. The start block in `AGENTS.md` and the description both help, and neither is certain.
