# waymark-trail

Two standalone skills that let an AI agent use a knowledge base of Markdown
documents in a Git repository (an Obsidian vault works too). No app, no
server, no install: you give your agent the URL of a skill.

> **Status: design phase.** The skills are not written yet. The specification
> is in [specs/](specs/).

- `personal-knowledge-base`: for one person with their own knowledge base.
- `team-knowledge-base`: for a knowledge base that several people write to.

This project is part of the waymark family. It works with or without
[waymark](https://github.com/ionpulse-dev/waymark).
