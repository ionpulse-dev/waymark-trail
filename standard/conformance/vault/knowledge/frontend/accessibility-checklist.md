# Accessibility checklist

Use this checklist for every new screen. A screen is done when all checks pass. The checks follow the common web guidelines, in plain words. The colors come from the [design tokens](design-tokens.md).

## Group 1

### 1. Every image has alternative text

**Why.** Screen readers read the text instead of the image.

**How to test.** Turn on a screen reader and move over the images.

**Pass when.** No problem is found in the mobile layout.

**Why.** People with color blindness miss the meaning.

**How to test.** Look at the page in grayscale.

**Pass when.** No problem is found in the mobile layout.

### 3. Text has enough contrast

**Why.** Low contrast is hard to read for many people.

**How to test.** Check the ratio with a contrast tool. It must be 4.5 or higher.
